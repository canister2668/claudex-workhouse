# 로컬 네트워크 접속

같은 집이나 사무실 네트워크에서만 사용할 경우 별도 도메인이나 Tunnel이
필요하지 않습니다.

```text
http://NAS-IP:3410
http://Linux-IP:3410
```

설치 계획에서 `로컬 네트워크만`을 선택하면 생성된 포트가 LAN에서
접근 가능하도록 바인딩됩니다. 자동으로 찾은 주소가 실제 브라우저에서
항상 도달 가능하다고 단정하지 않으므로 설치 후 직접 확인해야 합니다.

확인 순서:

1. 호스트에서 `/api/health/live` 확인
2. 다른 LAN 장치에서 서버 주소 열기
3. 방화벽과 포트 충돌 확인
4. SSE 진단
5. Worker WebSocket 진단

인터넷 공유기의 포트포워딩으로 Workhouse를 직접 공개하는 방식은
기본 설치에서 권장하지 않습니다.
