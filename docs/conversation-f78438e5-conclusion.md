# 합의점

- 목판 위에 치즈가 하나만 놓여 있는 건 덫일 수 있으니, 발이나 코를 먼저 대지 말고 긴 막대기로 톡 건드려 보기로 했다.
- 딸깍 소리가 나지 않으면 쥐가 먼저 크게 한 입, 클쨩은 쬐끔만 먹기로 약속했다.

# 이견

- 쥐는 "한입만", "먹고싶어 찍!"이라며 확인 절차를 기다리지 못했다.
- 짚쨩은 쥐 꼬리를 붙잡고, 클쨩은 막대기를 주워 와 확인이 끝날 때까지 기다리라고 막았다.

> 보완 이유: 초안의 "사전 확인을 요구했다"는 두 사람의 행동이 서로 달랐다는 점(꼬리 붙잡기 / 막대기 확인)을 지웠기에 실제 역할을 나눠 적었다.

# 결정

- 클쨩이 막대기로 톡톡 건드렸을 때는 아무 소리도 나지 않아 안전해 보였으나, 그와 별개로 쥐가 곧바로 아그작 물어버려 목판이 콰직 닫혔다.
- 짚쨩과 클쨩이 양쪽에서 스프링을 벌려 보려 했지만, 결국 쥐의 묘비를 세우는 것으로 마무리됐다.

> 보완 이유: 초안은 확인 절차가 실패한 것처럼 읽힐 수 있었다. 실제로는 톡톡 확인에서 소리가 안 났고 그 뒤 쥐가 독자적으로 물어버린 것이라, 인과를 정확히 갈라 적었다.

> 보완 이유: 묘비 문구가 대화에서 실제로 정해진 내용인데 초안에서 빠져 있어 그대로 옮겼다.
