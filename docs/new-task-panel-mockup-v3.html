왜 태그가 아니라 시트인가
  • 프리셋이 13개입니다. 앞의 3~4개만 태그로 노출하면 나머지를 숨길 기준이 없고, 사용자 설정은 텍스트 입력이라 태그로 표현이 안 됩니다
  • v3의 자체 규칙 — “값이 많고 거의 안 바꿈 → 행 + 시트” — 에 정확히 해당합니다. 앞선 시안은 이 규칙을 어겼습니다
  • 글로벌/세션 구분이 목록의 첫 항목이 됐습니다. 지금은 세그먼트가 위에, select가 아래에 따로 있어 어느 쪽이 적용 중인지 두 곳을 봐야 합니다
  • 세션에서 덮어쓰면 참여자 행에 “메스가키 · 이 세션만”이 액센트 색으로 남아, 전역과 다르다는 게 카드에서 바로 보입니다
  • 글로벌 톤은 프로바이더마다 다르게 저장돼 있어서(Codex 기본, Claude 플러팅하는 여사친) 현재 값을 첫 항목에 같이 적었습니다
