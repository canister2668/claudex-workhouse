새 작업 패널 — UI 정리 시안 v2

v1은 모든 설정을 “행 + 시트”로 통일했는데, 그러면 모델·추론 강도처럼 자주 바꾸는 값이 1탭에서 2~3탭으로 늘어납니다. v2는 바꾸는 빈도에 따라 컨트롤을 나누고, 겹침 문제는 “라벨은 항상 컨트롤 위”라는 한 줄 규칙으로 해결합니다. 단일 / 검토 / 대화 세 탭을 모두 담았습니다.

배치 규칙 — 컨트롤 선택 기준
형태쓰는 곳이 패널의 예
세그먼트2~3개, 서로 배타, 자주 바꿈세션 유형, 작업 방식, 진행 방식, 검토 깊이, 대화 길이
칩4~8개 또는 개수 가변, 자주 바꿈엔진, 모델, 추론 강도, 자동화 수준, 참여자
행 + 시트값이 길거나 개수가 많고, 거의 안 바꿈호스트, 작업 위치, 말투 프리셋, 타임아웃
카드선택마다 설명이 꼭 필요함검토 방법, 마무리 방식

핵심은 .modal label{display:block} 안에서 컨트롤이 inline-flex로 라벨 옆에 붙는 걸 없애는 것입니다. 라벨을 항상 자기 줄에 두면 드롭다운을 유지하든 칩으로 바꾸든 겹칠 수 없습니다.

현재 (문제 재현)

단일 탭. 라벨과 드롭다운이 한 줄에서 충돌합니다. 검토·대화 탭은 이 형태로 필드가 15~20개까지 늘어납니다.
