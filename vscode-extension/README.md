# Claudex Workhouse for VS Code

`Claudex Workhouse: Send Selection` opens the Workhouse task composer with the current Workspace, file, selection, cursor range, language, and nearby diagnostics. The command never starts a task by itself: review the generated prompt and execution settings in Workhouse first.

Set `claudexWorkhouse.serverUrl` to the Workhouse origin. Use HTTPS when the server is not on localhost.
